# Warehouse-Mobile-Robot-Fleet-with-A-Star-Path-Planning

A warehouse mobile robot fleet simulation featuring multi-agent A* path planning, collision avoidance, and task allocation.

## 🚀 Overview & Development Guidelines

This project focuses on simulating autonomous mobile robots (AMR) in warehouse environments:
- **Path Planning**: Multi-agent A* (A-Star) algorithm with dynamic obstacle avoidance.
- **Fleet Management**: Task dispatching, traffic coordination, and dead-lock resolution.
- **Simulation**: Grid-based warehouse layout with pick & drop stations and charging docks.
